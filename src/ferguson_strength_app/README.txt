LIFTLOG — iPHONE STRENGTH TRACKER
Version 1.0 | November 10, 2026

Built for your 12 machines:
Nautilus: Leg Press, Leg Extension, Leg Curl, Hip Adductor, Hip Abductor,
Inclined Row, Bicep Curl, Tricep Extension, Chest Press, Abdominal Crunch.
Hoist: Lat Pull Down, Seated Row.

WHAT IT DOES
- Large touch-friendly machine buttons.
- Records weight and repetitions for every completed working set.
- Logs cardio activity, duration, and optional resistance.
- Suggests your prior sets the next time you use the same machine.
- Saves one editable exercise entry per machine per date.
- Records optional effort, shoulder discomfort, and notes.
- Shows strength trends by machine and combined strength/cardio workout history.
- Lets you export CSV or save/restore a JSON backup.
- Works offline after installation from an HTTPS website.
- No account, password, analytics, or subscription required.

HOW TO INSTALL ON YOUR IPHONE
1. On a Mac or computer, extract the LiftLog_iPhone_App.zip file.
2. Open https://app.netlify.com/drop in your browser. Drag the extracted
   ferguson_strength_app folder onto the page and publish it. Netlify
   provides a unique HTTPS web address. You may want to create a Netlify
   account to retain control of your app address and updates.
3. Open that web address on your iPhone in Safari.
4. Use Safari's Share menu > Add to Home Screen > Add.
   If offered, enable "Open as Web App."
5. Tap the LiftLog icon on your iPhone to open the app. It will run in
   its own window, and should work offline after the first load.

IMPORTANT DATA NOTES
- Workout entries stay in your browser / iPhone web-app storage.
- No data is automatically synced between your phone and computer.
- Clearing site data, removing the app, or phone problems can erase
  locally saved workouts.
- After starting to use the app, periodically choose
  Settings > Download backup and save the file to iCloud Drive or Files.
- Settings > Restore backup restores those workouts on another device,
  but REPLACES existing entries on that device.
- The CSV file is for use in Excel, Numbers, or other software. CSV
  weight and volume columns use pounds regardless of the display units;
  cardio records include duration in minutes and optional resistance.
- The app does not automatically integrate with Apple Health.

TECHNICAL
This is a progressive web app (PWA), not a native App Store app.
All application files are included. No build step or extra libraries.
The code can be published through any static HTTPS hosting provider.
Do not upload personal backups to your publicly hosted app folder.

SUPPORT / CHANGES
To change or expand the app, update the source files and redeploy the
same folder to the same hosting site. Keep an external backup of your
workouts before making major changes.
